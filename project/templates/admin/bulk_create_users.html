Bulk Create Users

Instructions:

  • Enter user data in CSV format: username,email,first_name,last_name,role
  • One user per line
  • Valid roles: admin, asset_manager, employee
  • Only one admin user is allowed in the system
  • All users will be created with default password: password123
  • Users should change their password after first login
Example:

jane_smith,jane@company.com,Jane,Smith,asset_manager
bob_wilson,bob@company.com,Bob,Wilson,employee
